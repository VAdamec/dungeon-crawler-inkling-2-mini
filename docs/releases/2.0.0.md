# Dungeon Crawler 2.0.0

A new look for the village and dungeon, with matching heroes, monsters, bosses, items and effects.

- Directional character art, walking and wing poses, and steady wall torches.
- Connected dungeon walls, five distinct biomes, and corrected town bridge/building alignment.
- Refreshed boss introductions, defeats and the princess/dragon finale.
- Shorter player README and Help, with a separate player guide/bestiary and developer documentation.
- Fixed monster foot alignment and canvas-cache growth while cinematic characters change size.

Download **dungeon-crawler-2.0.0.zip**, extract it, and open **index.html** in a browser. The ZIP contains all five required runtime files. No installation, server or internet connection is needed to play.
